# خطة المونتاج والإنتاج

| العنصر | التنفيذ |
|---|---|
| الإيقاع | كل قسم: لقطة "المشكلة" (10–15 ث) ← عنوان الهدف ← شرح ← تشغيل مباشر في SQL Live ← تلخيص بسطر |
| الشاشة | تسجيل SQL Live بدقة 1080p، تكبير (zoom) 125% على محرر الكود وعلى الجدول الناتج |
| إبراز | مربع ملوّن حول الصفوف الناجية في كل Join، وNULL بلون أحمر |
| رسوم | Venn متحرك لكل Join، سهم يربط `dept_id` بين الجدولين، شريط تقدم أعلى الشاشة |
| انتقالات | قطع سريع عند التشغيل، وتلاشٍ عند تغيير القسم، وعنوان فرعي لكل قسم |
| صوت | تعليق بصوتك على مسار مستقل، مؤثر نقر خفيف عند تشغيل الاستعلام، موسيقى هادئة بخفض 20 ديسيبل تحت الصوت |
| ترجمة | نص عربي مزامن، وكود SQL بخط أحادي المسافة |
| أدوات | OBS للتسجيل · DaVinci Resolve أو CapCut للمونتاج · ffmpeg لتنظيف الصوت (`afftdn`, `loudnorm`) |
| المدة | ≈ 13–15 دقيقة |
